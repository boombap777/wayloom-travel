# 人工抽检协议（待执行）

每次数据版本冻结前，建议从 `pending_human_review.jsonl` 中至少抽检 30 条，并覆盖完整需求、各单字段缺失、相对日期、绝对日期、单/多人和有/无可选偏好。

对每条样本记录：

1. 用户表述是否自然、没有模板拼接痕迹或语意冲突；
2. 所有结构化字段是否来自明确表达或确定性日期归一化；
3. `clarify` 与 `tool_call` 是否符合必填字段规则；
4. DPO rejected 输出是否是合理的常见错误，而非无意义噪声；
5. 是否存在不应出现的实时价格、库存、预订承诺或个人敏感数据。

审核完成后，应在每条记录写入真实 `reviewer`、`reviewed_at`、`review_status` 和 `review_note`，并重新生成 manifest。未完成前，本项目只能称为“程序审计的合成数据”。
